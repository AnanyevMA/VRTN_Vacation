# 🧵 Планировщик отпусков (Швейное производство)
### Мультиагентная система планирования отпусков (MAX Messenger + Vue 3 Dashboard + CSP Solver)

Комплексное решение для автоматизированного сбора пожеланий сотрудниц швейной фабрики (Республика Хакасия), детерминированной оптимизации расписания (CSP-солвер) и согласования графиков отпусков с интеграцией в корпоративный мессенджер **MAX** и интерактивной веб-панелью управления для руководства.

---

Для отладки и демонстрации проекта доступны 3 удобных варианта:

### Вариант 1: Постоянный бесплатный онлайн-сервер 24/7 (Render.com)
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/AnanyevMA/VRTN_Vacation)

2. Нажмите **Apply** — сервис соберется за 1 минуту и предоставит **постоянный HTTPS-адрес** (например, `https://vrtn-vacation-planner.onrender.com`).
3. Сервер работает 24/7 (в бесплатном тарифе при отсутствии обращений он засыпает и моментально просыпается при переходе по ссылке), не требует оплаты и автоматически обновляется при каждом коммите в ветку `main`!

### Вариант 2: Запуск 24/7 на собственном VPS (Docker)
Если у вас есть собственный VPS-сервер (Ubuntu/Debian), запустите дашборд одной командой:
```bash
git clone https://github.com/AnanyevMA/VRTN_Vacation.git
cd VRTN_Vacation
docker compose -f deploy/docker-compose.yml up -d --build
```
Дашборд будет доступен 24/7 по адресу `http://<IP-вашего-VPS>:8000` с автоматическим перезапуском при перезагрузке сервера.

## 🌟 Ключевые возможности и бизнес-логика

### 1. Соблюдение трудового законодательства и региональной нормы (Хакасия)
- **36 календарных дней** ежегодного оплачиваемого отпуска (28 основных + 8 дополнительных дней за суровые климатические условия юга Сибири).
- **Статья 125 ТК РФ:** минимум одна неделимая часть отпуска должна быть **не менее 14 дней непрерывно**.
- Автоматический контроль остатка дней и предотвращение перерасхода.

### 2. Производственные ограничения фабрики (CSP-Солвер)
- **Квоты по должностям:** ограничение на одновременный уход критических специалистов (не более 1 закройщика, технолога, механика, мастера).
- **Квоты по сменам:** ограничение одновременного отсутствия швей одной бригады/смены (например, не более 2 швей на 1-й или 2-й смене).
- **Группы несовместимости сотрудников:** запрет одновременного отпуска для взаимозаменяемых сотрудниц (настраивается в дашборде мультиселектом).
- **Блэкаут-периоды:** запрет на отпуска в периоды сдачи сезонных коллекций, школьной формы (15–31 августа) и годовой инвентаризации.

### 3. Интеграция с мессенджером MAX и безопасность
- Авторизация сотрудниц строго по номерам телефонов из базы фабрики (`Employee.bot_access`: APPROVED, PENDING, BLOCKED).
- Многоуровневый накопительный черновик (`EmployeeDraft`) — сотрудница может называть периоды по частям на естественном русском языке.
- Команда `/admin` для администраторов фабрики с возможностью одобрения номеров прямо из мессенджера.
- Встроенный интерактивный веб-симулятор смартфона для проверки сценариев диалога.

### 4. Интерактивный веб-дашборд руководителя (Vue 3 + Tailwind CSS)
- **Календарь-Гант:** переключение годов (2026, 2027+), масштабирование (месяц, 2 недели, неделя, день), подсветка коллизий.
- **Реестр сотрудниц:** поиск, фильтрация, привязка смен/цехов, импорт из Google Таблицы фабрики.
- **Матрица правил:** визуальное управление квотами ролей, квотами смен, блэкаут-периодами и непересекающимися группами.
- **Экспорт отчетов:** выгрузка унифицированной формы **Т-7 (Excel .xlsx)** и CSV.

## 🚀 Локальный запуск (Windows / Linux)

### 1. Быстрый запуск на Windows
Дважды кликните по файлу **`Запуск_Планировщика.bat`** — сервер запустится на `http://127.0.0.1:8000`, и браузер откроется автоматически.

### 2. Запуск через консоль
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python run_server.py
```
Адрес панели: **`http://127.0.0.1:8000`**

### 3. Запуск автоматических тестов
```bash
pytest -v
```
*В проекте реализовано 19 интеграционных и юнит-тестов (CSP-солвер, ТК РФ, смены, группы, бот MAX, парсер дат).*

```
└── tests/                       # 19 тестов pytest
```
